# Quant Finance Bible (20188)

- `QuantBible.pdf` — the compiled Bible (theory + every past exam with solutions + formula sheet).
- `ch00.md` … `ch99.md` — one Markdown file per lecture chapter (theory, past exam questions, tutorial placeholder).
- `exams/` — past-exam material sorted by chapter (`th_` = theory questions, `ex_` = exercises).
- `latex/` — build system. Rebuild with `python3 latex/build.py` (needs pandoc + pdflatex with tcolorbox, pgfplots).
